#  NovaFlix

NovaFlix is a web-based movie and TV series management platform designed to organize, browse, and stream multimedia content through an intuitive and responsive interface.

## Features

-  Movie and TV series catalog
-  Search and filtering system
-  Favorites management
-  User profiles
-  Administrative dashboard
-  Responsive design
-  User authentication
-  Integrated media player

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)
- Python (Backend)
- SQLite

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/novaflix.git
   ```

2. Navigate to the project folder:
   ```bash
   cd novaflix
   ```

3. Install the required dependencies.

4. Run the application:
   ```bash
   python app.py
   ```

5. Open your browser and access the local server.
